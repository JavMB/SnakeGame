Un juego clásico de Snake desarrollado en Java usando Swing.

## Cómo Ejecutar

1. Clona el repositorio
2. Abre el proyecto con tu IDE favorito
3. Ejecuta la clase `Main.java`

## Requisitos

- Java 17 o superior
- Gradle
